Face Emotion Detection Web App

A simple and beautiful Flask web application that detects human emotions from:

 Uploaded Images
 Live Webcam Video Stream

The app uses DeepFace, TensorFlow, and OpenCV for analyzing facial expressions such as:
happy, sad, angry, neutral, surprise, fear, disgust.

 Features
 1. Image Upload Emotion Detection

Upload any photo containing a face

System analyzes and displays the dominant emotion

Returns the predicted emotion + displays the uploaded image

 2. Real-Time Webcam Emotion Detection

Live video streamed from your webcam

Face is detected continuously

Emotion is displayed in real-time on the video feed

 3. Beautiful Pink-White Soft UI

Soft aesthetic design

Clean cards

Styled buttons

Modern UI with rounded corners
